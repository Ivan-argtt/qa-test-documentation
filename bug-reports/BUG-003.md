# BUG-003 – Typo in checkout confirmation message

## Summary

A spelling error is displayed in the order confirmation message after completing a purchase.

## Environment

* OS: Windows 11
* Browser: Google Chrome
* Browser Version: Latest available version
* Environment: Test Environment

## Preconditions

* The user is logged in.
* The user has completed a valid purchase.

## Steps to Reproduce

1. Log in to the application.
2. Add a product to the shopping cart.
3. Complete the checkout process.
4. Observe the order confirmation message.

## Expected Result

The confirmation message should be displayed without spelling or grammatical errors.

## Actual Result

A spelling error is displayed in the confirmation message.

## Severity

**Minor**

## Priority

**Low**

## Status

**Open**

## Impact

The defect does not affect the functionality of the application but negatively impacts the perceived quality and professionalism of the user interface.

## Recommendation

Correct the spelling error in the confirmation message.
