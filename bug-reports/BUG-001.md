# BUG-001 – Login accepts invalid password

## Summary

The application allows users to log in using a valid email address and an incorrect password.

## Environment

* OS: Windows 11
* Browser: Google Chrome
* Browser Version: Latest available version
* Environment: Test Environment

## Preconditions

* A valid user account exists.
* The user is logged out.

## Steps to Reproduce

1. Open the login page.
2. Enter a valid registered email address.
3. Enter an incorrect password.
4. Click the **Login** button.

## Test Data

* Email: `test.user@example.com`
* Password: `WrongPassword123`

## Expected Result

The login attempt should be rejected and an appropriate error message should be displayed.

## Actual Result

The application successfully authenticates the user despite the incorrect password.

## Severity

**Critical**

## Priority

**High**

## Status

**Open**

## Impact

This issue represents a serious authentication and security problem because unauthorized users may potentially gain access to user accounts.

## Recommendation

Review the authentication validation logic and ensure that the password provided by the user is correctly validated against the stored credentials.
