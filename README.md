QA Test Documentation – E-commerce Application

## Project Overview

This project demonstrates a QA testing process for a fictional e-commerce web application.

The purpose of the project is to demonstrate practical knowledge of software testing, test documentation, defect reporting and QA methodologies.

## Testing Scope

The testing activities cover the following areas:

* Functional Testing
* UI Testing
* Positive and Negative Testing
* Regression Testing
* Exploratory Testing
* Usability Testing
* Bug Reporting

## Application Features

The fictional application includes:

* User registration
* User login
* Product search
* Product filtering
* Product details
* Shopping cart
* Checkout
* Logout

## Test Documentation

The following documentation will be included in this repository:

* Test Plan
* Test Scenarios
* Test Cases
* Bug Reports
* Test Summary Report

## Tools & Technologies

* GitHub
* Microsoft Excel
* Jira
* Chrome DevTools
* ISTQB Testing Principles

## QA Approach

Testing activities are based on software testing principles and best practices, with a focus on identifying defects, validating requirements and ensuring a positive user experience.
